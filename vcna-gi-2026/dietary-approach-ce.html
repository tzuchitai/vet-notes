犬貓慢性腸病的飲食策略

作者：Cecilia Villaverde（論文整理）

⭐ 必記重點

  • 食物反應性腸病占 CE：貓約 60%、犬 38–89%；非食物反應性的狗 1 年後也可能被重新分類為食物反應性
  • 三大類商業處方：腸胃處方（高消化率）、排除飲食（新蛋白／水解／胺基酸）、高纖飲食；同一類中一種失敗不代表整類失敗
  • 首選：非 PLE 的 CE → 排除飲食；PLE → 低脂（腸胃或水解）；單純結腸炎 → 高纖
  • 犬脂肪分級：低脂 1.7–2.9 g/100 kcal、中脂 3–5、超低脂 < 1.7（多需自製）；貓通常不建議限脂
  • 犬纖維（TDF）分級：低 < 2、中 2–4、高 > 4 g/100 kcal；貓 < 1、1–2.5、> 2.5；粗纖維會大幅低估 TDF
  • 至少試 3 種處方，每種至少 2 週（要涵蓋發作間隔）
  • 犬 EPA＋DHA 125 mg/kg^0.75；鈷胺素低就補；沒有低血鈣不建議補維生素 D
  • 零食 ≤ 每日熱量 10%，且要符合主食策略；換食至少 1 週
🎯

1. 飲食在慢性腸病的角色

▾
  • 營養透過對腸上皮的營養作用、調節菌相、影響蠕動等方式，影響腸胃功能與結構
  • 每隻 CE 病患都要做飲食試驗，找出可主要靠飲食控制的食物反應性腸病
  • 食物反應性比例：貓約 60%、犬 38–89%；這些病例飲食本身就是維持緩解的治療
  • 非食物反應性病例，飲食仍是支持療法；一研究中部分免疫調節反應性 CE 犬在診斷 1 年後被重新歸類為食物反應性 → 這些病例也值得用 CE 處方
🧬

2. 飲食成分逐項看

▾

能量

  • 消化不良／吸收不良 → 能量攝取不足、體重下降；小腸型 CE 比大腸型更常見；食慾差也會加重
  • PLE 犬常見低體態分數；CE 整體的過瘦盛行率未有報告
  • 低 BCS、有體重下降者用高能量密度飲食；能量密度主要取決於脂肪，纖維與水分會稀釋

消化率

  • 高消化率飲食在腸胃功能異常時能更有效率提供營養；未消化物進入大腸會有害
  • 多數 CE 處方同時有多種策略，很難單獨評估「高消化率」本身的效果

蛋白質

  • 傳統用限制成分＋新蛋白降低致敏性、調節免疫
  • 近來水解蛋白較普遍：把蛋白切成寡胜肽、改變抗原決定位，也提高消化率
  • 兩種策略沒有直接比較研究，但近期犬研究多用水解飼料；犬另有純化胺基酸飲食
  • CE 犬貓血漿胺基酸會改變（如色胺酸下降），但胺基酸補充未經測試、目前不建議

脂肪

  • 每克熱量是蛋白與碳水的 2 倍以上、適口性好 → 適合瘦、食慾不穩的病患
  • CE 時脂肪消化率可能下降，未消化脂肪傷害結腸
  • 犬 CE（尤其 PLE）對不同程度限脂有正面反應；淋巴管擴張時減少脂肪可降低淋巴流量與乳糜管壓力，其他類型 PLE 也可能受益
  • 貓通常不建議限脂：一研究比較兩種不同脂肪含量飲食治療貓慢性腹瀉，效果沒差
  • Omega-3（EPA＋DHA）：常建議用於抗發炎，但前瞻研究少；犬建議 125 mg EPA＋DHA / kg^0.75
  • 中鏈三酸甘油酯（MCT）：理論上經門脈吸收、淋巴受損時仍可提供能量，但沒有臨床研究支持；唯一的 18 犬椰子油自製飲食研究同時用了限制成分與新蛋白

纖維

  • 小腸無法消化、大腸可部分或完全發酵的植物性成分，種類很多
  • 依水中分散性分可溶 vs 不可溶；也可依發酵速度、黏度、保水力分類；可溶不一定快速發酵
  • 能促進有益菌生長的可發酵纖維＝益生元纖維，常加在 CE 飲食；發酵產物營養黏膜、強化屏障
  • 一般 CE 飲食會壓低總膳食纖維（TDF）以維持高消化率與能量密度；但結腸炎用高纖飲食在多篇犬研究有改善

其他

  • 鈷胺素（B12）：攝取或吸收下降都會缺乏；貓三體炎併發胰臟炎時內在因子分泌也可能下降
  • 維生素 D：犬 CE（尤其 PLE 與免疫抑制劑反應型）血清維生素 D 指標較低
📋

3. 擬定餵食計畫

▾

營養評估

  • 評估動物、飲食、環境三方面的營養風險因子；每次回診都要做
  • 完整詳細的飲食史極重要：目前的能量與營養攝取、過去試過什麼、換食與症狀變化的關聯
  • 飼主與轉診醫師提供的飲食史常不完整 → 可用 WSAVA 營養工具包的飲食史表格

4. 三類商業處方

▾

腸胃處方（GI diets）

  • 完整均衡、高消化率；常含益生元纖維與 EPA＋DHA
  • 適應症廣：急性腸胃炎、術後、部分肝與胰臟病，也可用於 CE
  • 貓慢性腹瀉的中期研究顯示糞便品質改善，但缺長期資料
  • 犬研究：腸胃處方與水解處方 3 個月時都改善，但 6 個月到 1 年後水解組維持無症狀的比較多 → 腸胃處方可能不是長期緩解的最佳選擇

低脂腸胃處方（犬）

超低脂< 1.7（目前多半只能自製）
低脂1.7–2.9
中脂3–5
  • 常用於胰臟炎；在部分 PLE 犬效果好（商業、自製或合併使用）
  • 非 PLE 病例資料少，作者經驗是其他方法失敗時值得一試
  • 低脂處方能量密度較低；過瘦／體重下降時選乾糧較能補足熱量；沒有限脂適應症時不要用
  • 要靠飲食史判斷：市售低脂處方跟原本的飲食比起來，是否真的有降低脂肪，或需要自製超低脂

排除飲食（「低過敏」）

  • 完整均衡、限制成分（通常一種蛋白＋一種碳水），用新蛋白或水解蛋白降低抗原性；犬在部分地區有純化胺基酸飲食
  • 通常是找出食物反應性 CE 的第一個嘗試（尤其水解）
  • 水解飼料另有調節菌相的效果，也高消化率、含益生元與 omega-3
  • 犬有許多研究支持（ACVIM CIE 共識有回顧）；貓證據有限
  • 對新蛋白或其他水解飼料無效的犬，可改用更高度水解或胺基酸飲食
  • 新出現水解＋低脂處方，同時降低抗原性與脂肪 → 適合 PLE 或合併對脂肪敏感疾病的 CE

  • 最佳纖維量與種類因個體而異；結腸炎病例要多試幾種高纖飲食再放棄

原文 Box 2：自製飲食

  • 可組合各種策略（但做不到蛋白水解或純化胺基酸）
  • 優點：可客製、照顧併發疾病、病患拒吃處方時可用；可做到超低脂（市售低脂無法控制的 PLE）
  • 缺點：比乾處方貴、費時費空間；可能因沒有營養檢測、配合度差或配方不當而營養不足
  • 只在沒有合適商業選擇時建議，且配方應由獸醫營養專科醫師提供

5. 試幾種、試多久、怎麼選

▾

數量與時間

  • 一些研究建議至少試 3 種處方，有些病患需要更多 → 要有系統、有紀錄
  • 不太病、體態好的穩定病患，花時間多試幾種沒有壞處
  • 每種至少 2 週；反覆發作的病例要試到涵蓋發作間隔
  • 部分病患在無症狀 14 週後可回到維持飲食，但 PLE 較不可能，需個別評估
  • 處方只要對生命階段完整均衡、預算允許，長期吃沒有營養上的壞處
  • 非食物反應性病患：需更多檢查，並維持在耐受最好的處方

怎麼選第一種

情境首選
非 PLE 的 CE排除飲食（水解或新蛋白）
PLE低脂（腸胃低脂或水解低脂）
單純結腸炎高纖飲食
  • 同類中再依生命階段、適口性、能量密度、價格、取得性、想要的脂肪與纖維量、飼主偏好挑選
  • 濕食：保水、適口性較好，但較貴、能量密度低很多
  • 乾糧：小體積提供較多熱量 → 過瘦、體重下降的病患優先

6. 補充品、零食與餵食方式

▾

補充品

  • 先確認飲食是否完整（不均衡自製飲食可能缺乏）
  • 低鈷胺素 → 補充 B12
  • 維生素 D：維生素 D 指標低但離子鈣正常的 PLE 犬，口服 cholecalciferol 400 IU/kg vs 安慰劑 3 週沒有臨床益處；有中毒風險 → 沒有低血鈣時不建議補
  • 纖維補充（無法用高纖飲食時）：洋車前子殼、纖維素、菊糖；劑量未明確，作者通常從每天 ½–1 茶匙分餐開始，每週調升到有效或出現副作用；可溶纖維過多會加重腹瀉，不可溶過多會有大量硬便
  • Omega-3（魚油、藻油）：處方劑量不足時補；產品 EPA＋DHA 至少 20–30%，並注意污染物與脂溶性維生素（可能中毒）

零食

  • 任何不均衡的東西都算零食，≤ 每日熱量 10%，且要符合主食策略 → 排除飲食期間避免一般零食
  • 有廠商出同成分的水解零食；新蛋白飲食可買同種肉類自己煮成配料
  • 試驗有效且穩定後，想給的零食（如水果、蔬菜）一次加一種評估耐受

每日餵食量

  • 依飲食史知道目前攝取量，再調整到體重與 BCS 目標（成犬貓體重穩定、體態理想）
  • 不知道目前攝取量時，可用包裝建議或公式起算，但誤差大，需每 2 週調整

餵食方式

  • 任食：適合過瘦、挑食、家中情況允許時
  • 定量：適合易胖、多寵家庭
  • 多餐可減輕腸道負擔
  • 換新飲食要有清楚的轉換說明，緩慢轉換至少 1 週，可及早發現問題並減少腸胃不適

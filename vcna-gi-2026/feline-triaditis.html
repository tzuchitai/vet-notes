⭐ 必記重點

  • 三體炎＝貓胰臟、肝膽、小腸同時發炎；是因果還是只是關聯，仍未知
  • 胰臟炎 > 95% 特發性；與體態、高脂飲食、亂吃沒有被證實的關聯；三體炎中最常見的可能是慢性胰臟炎
  • 約 84% 的貓膽管與胰管在進入十二指腸前匯合；51% 的貓十二指腸大乳頭有明顯淋巴球聚集
  • Spec fPL ≥ 8.8 µg/L 對貓胰臟炎高度特異；超音波正常不能排除胰臟炎、膽管炎或 CIE
  • B12 ≤ 400 ng/L 支持小腸疾病；明顯低下要驗 TLI 排除 EPI；膽汁淤積的貓不要驗膽酸
  • 膽管炎採樣：膽汁培養比肝穿刺培養敏感；膽囊超音波正常者培養陽性機率低
  • 胰臟炎治療四支柱：輸液、營養、止痛、止吐；厭食 > 48–72 小時就要輔助餵食；第一天給 RER 的 1/4–1/3
  • 急性嗜中性膽管炎：依藥敏用抗生素 4–6 週；淋巴球性膽管炎：prednisolone 1–2 mg/kg/天（優於單用 UDCA）

1. 三體炎的三個組成

▾

胰臟炎

  • 以前被認為罕見，現在因警覺與檢查普及而更常被發現
  • 作者偏好依臨床表現稱為「急性」「慢性」「慢性急性發作」，而非組織學分類（很少切片，且臨床表現與組織浸潤不一定相符）
  • 慢性胰臟炎較常合併其他疾病，可能是三體炎中最常見的形式
  • 沒有明確的品種、年齡等傾向；> 95% 特發性
  • 與體態、高脂飲食、亂吃都沒有被證實的關聯（和狗不同）

膽管炎／膽管肝炎

  • 膽管發炎＝膽管炎；延伸到肝實質＝膽管肝炎；全球常見
  • WSAVA 分三大類（第四類破壞性／膽管減少性很少見）：
類型組織特徵病因
嗜中性（化膿性）急性：門脈區嗜中性球與水腫；慢性：混合浸潤＋膽管增生與纖維化（兩者有重疊）細菌感染（經門脈移位或上行）；常見 *E. coli*、*Enterococcus*；許多合併膽囊炎；慢性者常有膽汁流動受阻 → 要積極找阻塞
淋巴球性門脈區淋巴球與漿細胞浸潤，不同程度膽管增生與纖維化推測免疫介導（以淋巴漿細胞為主、對免疫抑制有反應、可測到抗肝抗體）；找到的細菌可能是續發
肝吸蟲相關大膽管擴張＋膽管周圍與門脈纖維化熱帶與亞熱帶；貓吃了受感染的蜥蜴；蟲體住在膽囊與膽管

慢性發炎性腸病（CIE）

  • 持續或反覆腸胃症狀 ≥ 3 週，排除其他原因，且組織學有腸道發炎
  • 分為食物反應性（FRE）、免疫抑制反應性（IRE，即 IBD）、小細胞淋巴瘤（SCL）；懷疑部分 IRE 會進展為 SCL
  • FRE 貓可能較年輕、SCL 較老，但重疊很大
  • 致病：菌相、飲食成分、黏膜免疫、宿主遺傳的複雜交互

2. 發炎怎麼串連？四種假說（原文圖 1）

▾
  • 四種假說不互斥，界線也可能模糊

解剖連續假說

  • 貓的特點：總膽管與胰管在進入十二指腸前匯合、小腸比狗短、十二指腸細菌濃度較高 → 細菌較易上行到肝與胰
  • 膽汁流動靠壓力梯度：嘔吐或阻塞使壓力上升 → 膽汁可能逆流進胰臟與肝臟
  • 支持證據：病貓肝與胰臟中的細菌來自腸道；約 84% 的貓有膽胰管匯合構造；組織學研究發現匯合構造與「三體炎」相關

胰臟起始假說

  • 胰臟炎經直接傷害或全身性發炎反應造成腸道發炎 → 菌相失調、屏障失能、細菌移位到肝與胰
  • 實驗模型：*E. coli* 能移位到發炎的胰臟
  • 微生物蛋白與宿主的分子擬態可能引發自體免疫
  • CIE 與失調＋胰臟炎 → 反應性肝炎，可能嗜中性膽管炎

腸道起始假說

  • 變體一（細菌移位）：CIE → 失調 → 屏障受損 → 細菌移位到肝與胰；或腸道發炎及其症狀（嘔吐）使細菌逆流
    • 發炎性肝病貓的肝內細菌多位於門脈血管、竇狀隙、肝實質 → 有人認為支持血行或移位而非沿膽管上行（有爭議）
  • 變體二（免疫失調）：CIE → 失調、通透性上升、低度細菌移位 → 免疫耐受喪失 → 免疫介導的肝胰損傷
    • 人類：自體免疫性胰臟炎與一種膽管炎與 IBD 相關

十二指腸乳頭中心假說

  • 124 隻貓中 51% 在十二指腸大乳頭（MDP）有明顯淋巴球聚集，可能是三體炎的起點
  • MDP 發炎與三體炎風險增加相關；嚴重 MDP 病變也與總膽管結石等相關 → 可能造成膽道阻塞、膽管炎，以及膽酸或細菌逆流進胰臟

也可能只是共同易感性

  • 各器官也可能由不同機制發炎，同時出現只是反映共同的疾病易感性或關聯，不一定是因果

3. 診斷

▾
  • 確診需組織病理，但臨床很少做；多依症狀、理學檢查、血檢、影像、細針抽吸細胞學與培養做推定診斷
  • 最低資料庫＋其他鑑別：視個案測 TT4（甲亢）、TLI（EPI）；依地區做感染篩檢（*Histoplasma* 尿抗原、弓蟲 IgG/IgM、*T. foetus* 糞便 PCR 等）

血液學與生化

  • 胰臟炎：白血球低下可能預後較差；低血糖與低血鈣可能預後差；高膽紅素可來自重症膽汁淤積或肝外膽道阻塞；氮血症可為腎前或腎性；輕度低白蛋白來自負急性期反應
  • 膽管炎：嗜中性球增多與帶狀核較常見於嗜中性型；可能有發炎性貧血；肝指數 ALT > AST > GGT > ALP；高球蛋白尤其見於淋巴球性
  • CIE：CBC 與生化常正常，偶見泛低蛋白血症

特定生物標記

  • 胰脂酶（PL）：健康時 < 1% 進入血液，胰臟炎時大量漏出
    • 免疫法（如 Spec fPL）：≥ 8.8 µg/L 對貓胰臟炎高度特異
    • 催化法：測酵素活性，有些會測到胰外來源的脂酶，特異性可能較低（依廠牌而異）
  • 膽管炎很少有明顯肝功能不全；膽汁淤積的貓測膽酸不會多提供肝功能資訊，應避免
  • B12 ≤ 400 ng/L（低或低正常）支持小腸疾病；明顯低下要驗 TLI 排除 EPI

影像

  • X 光：胰臟炎可能因積液漿膜細節變差；膽管炎可見肝腫大和／或膽結石；CIE 特徵少
  • 慢性胰臟炎超音波：厚度異常、邊緣不規則、混合回音、高回音點
  • 低回音胰臟不代表預後比高回音或混合回音差（雖然坊間這樣傳）
  • 超音波敏感度不一，沒看到胰臟異常不能排除胰臟炎；取決於嚴重度、時間點、操作者技術、機器
  • 膽管炎：肝臟沒異常不能排除；要仔細找影響膽汁流動的病（膽結石、肝外膽道阻塞、囊性肝病）
  • CIE：沒有超音波病灶不能排除

細針抽吸

  • 胰臟 FNA 多用於局部病灶與積液
  • 懷疑膽管炎應採膽汁：受訓者操作相對安全；膽囊超音波正常者培養陽性機率低
  • 膽汁送細胞學與培養；正常膽囊沒有核心菌相，培養到的菌可能參與致病
  • 膽汁培養比肝穿刺培養敏感；有些醫師合併肝與膽汁樣本
  • 細胞學沒看到細菌，培養仍可能陽性
  • CIE 很少需要 FNA

推定與確定診斷

  • 可能是局部病灶 → 每個組織要取多塊切片
  • 沒有切片時：胰臟炎依超音波＋PL；膽管炎依生化＋超音波＋細胞學與培養；CIE 依症狀、排除其他原因、治療反應（排除 EPI 後，低鈷胺素也有幫助）
  • 治療無反應時，可能需要切片指引長期處置

4. 胰臟炎的治療

▾
  • 不要一套流程打天下，依病患問題清單靈活處理
  • 以支持與症狀治療為主；四支柱：① 輸液 ② 營養 ③ 止痛 ④ 止吐／止噁心；目前沒有標靶治療

輸液

  • 貓缺乏對照研究，參考人類 RCT：積極方案（20 mL/kg 推注後 3 mL/kg/h）vs 溫和方案（低血容才給 10 mL/kg，之後 1.5 mL/kg/h）→ 積極組輸液過量風險較高、疾病緩解沒有改善
  • 作者做法：依估計脫水、維持需求、持續流失設計個別計畫，定期量體重調整；首選平衡等張電解質液

營養

  • 以前「讓腸胃休息」的觀念：受傷的腺泡細胞對刺激的反應不同於健康細胞，且禁食可能有害 → 現強調早期腸道營養
  • 回溯研究：鼻腸管餵食安全、耐受良好
  • 作者建議：胰臟炎貓厭食 > 48–72 小時就輔助餵食，避免肝脂肪沉積（會讓預後變差）
  • 可經鼻腸管給獸醫液態飲食或打碎的重症處方；第一線選高消化率（腸胃）處方
  • 小心人用液態飲食：可能缺乏貓必需胺基酸（如精胺酸）
  • 餵食量依 RER＝70 × 體重^0.75：第 1 天約給 1/4–1/3 RER，數天內依耐受增加到 75–100%；每餐最多約 5–10 mL/kg
  • 目標是「先有一些營養」，不是快速達到 100% RER；靜脈營養很少需要
  • 無法輔助餵食時：高適口性、提供多種形態（乾、濕）與口味、加溫、安靜環境、食慾刺激劑（mirtazapine）

止痛

  • 假設胰臟炎的貓都有腹部不適，即使檢查時不明顯
  • 輕中度痛：buprenorphine；重度：純 µ 促效劑（如 fentanyl）
  • 門診：經黏膜 buprenorphine；也有長效經皮劑型
  • Gabapentin 可用於輕度疼痛，但止痛效果證據有限

止吐與抗生素

  • 止吐止噁心可能增加自主進食（劑量見下表）
  • 胰臟炎是無菌過程，不建議例行抗生素；只用於細菌性續發併發症或共病（如吸入性肺炎）、懷疑或確認胰臟感染（胰臟膿瘍）、懷疑敗血症

免疫抑制

  • 部分慢性胰臟炎會考慮，但方案未定
  • Cyclosporine 可降低 Spec fPL，但尚未證明明顯臨床改善
  • 免疫抑制前常先做弓蟲篩檢

5. 膽管炎與 CIE 的治療

▾

膽管炎／膽管肝炎

  • 急性嗜中性膽管炎需抗生素，最好依培養與藥敏；合併膽汁、組織、膽結石樣本可提高檢出率
  • 抗藥菌常見；革蘭陽性、陰性、需氧、厭氧都有 → 結果未出時用廣效抗生素
    • Amoxicillin-clavulanic acid 常用，會濃縮在膽汁
    • 也有人用 fluoroquinolone 或強化型青黴素＋fluoroquinolone
    • 經驗性使用 pradofloxacin 可能屬不當使用（光譜太廣）
  • 療程通常 4–6 週，依反應調整
  • 輔助：抗氧化劑（SAMe、silybin、維生素 E、N-acetylcysteine）、熊去氧膽酸（利膽、可能抗發炎）、維生素 K1（黃疸或凝血異常）
  • 培養陰性、抗生素無效、組織學為淋巴球性膽管炎 → 免疫抑制
    • Prednisolone 與 UDCA 相比可延長存活、減少組織發炎
    • 難治或 prednisolone 禁忌（如糖尿病）→ modified cyclosporine 或 chlorambucil
  • 處理膽道阻塞的潛在原因（膽結石）或慢性膽囊病，考慮手術

慢性發炎性腸病

  • 用依序治療試驗同時診斷與治療；相當比例 CIE 貓完全或部分飲食反應
  • 作者的第一線：飲食試驗；2 週內沒改善且病患穩定 → 試第二種；有些貓要試好幾種
  • 對飲食無反應、排除其他原因 → 可能需要腸道切片
  • 切片證實非特異性發炎（如淋巴漿細胞性）→ prednisolone 試驗；其他發炎型態 → 加做檢查（如感染篩檢）
  • 也有醫師在飼主知情同意下直接試 prednisolone
  • 對 prednisolone 無反應 → 考慮 SCL 等其他病因；prednisolone 難治 CIE 或 SCL 常加 chlorambucil（q48–72h，緩解後可再減量；難餵藥可用脈衝劑量），定期驗 CBC
  • B12 ≤ 400 ng/L 或沒測時就補鈷胺素

7. 預後與 Clinics Care Points

▾
  • 預後取決於有哪些疾病與嚴重度；多數輕中度病例長期預後良好（經驗性）
  • 臨床上不必糾結「是因果還是關聯」，應依病患問題清單與最可能的診斷，擬定完整的診斷與治療計畫

作者的 Clinics Care Points

  • 胰臟、肝膽、小腸同時發炎的臨床頻率相對高；懷疑或診斷其中一個，就要評估是否有其他兩個
  • 確診需組織病理，但臨床診斷常綜合症狀、血檢、影像、細胞學與培養
  • 處置依問題清單，可能包含支持治療、抗生素和／或免疫抑制劑，取決於潛在疾病

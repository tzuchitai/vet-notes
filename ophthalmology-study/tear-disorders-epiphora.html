⭐ 本場重點

  • 流淚是結果，不是診斷：沿著「分泌 → 分布 → 收集 → 排出」四段找問題在哪裡
  • 突然單側流淚＋瞇眼、畏光 → 先找疼痛來源：角膜潰瘍、異物、異位睫、葡萄膜炎、青光眼（螢光染色＋眼壓）
  • 長期流淚、眼表平靜 → 看眼瞼貼合、淚點位置、引流功能
  • 水液量足夠 ≠ 淚膜正常；眼周濕 ≠ 分泌正常（顏面神經病變可能同時閉眼不全＋神經性乾眼）
  • 三種引流檢查互補：Jones test 陰性不等於阻塞（短吻犬可能從副開口流到後鼻腔）；沖得通也不等於平常排得好
  • 🎤 蔡醫師：早期、發炎性的鼻淚管阻塞，局部類固醇效果很好；長期（幼犬起就有淚痕）的就沒效。麻醉下通鼻淚管成功率大約 10 隻 1–2 隻
  • 🎤 病歷用詞：原因未明或偏向阻塞 → epiphora；已找到刺激源（疼痛、異物、神經性）→ hyperlacrimation
🎯

開場：主訴是「眼睛濕」

▾

🎤 錄音 濕的來源與淚痕

  • 🎤 眼周濕可能來自分泌增加，也可能是眼淚沒有被有效收集或排出。
  • 🎤 淚痕反映的是眼淚接觸毛髮後留下的變化，不能直接用顏色或範圍判斷當下的分泌量。
  • 🎤 問診時先分清楚飼主說的是長期染色、持續濕潤，還是最近突然大量流眼淚。

💡 逐字稿寫「我們直接用它的顏色或範圍去判斷」，依上下文應是「不能直接用」——淚痕是長期累積的結果。

🎤 錄音 名詞：epiphora vs hyperlacrimation（蔡醫師）

Epiphora（溢淚）

  • 眼淚溢出來的統稱，看到淚水變多就可以寫
  • 原因還沒找到時用
  • 確定鼻淚管阻塞時也寫 epiphora

Hyperlacrimation（淚液分泌過多）

  • 已經找到刺激源：疼痛、不舒服、異物
  • 或神經性的分泌增加
  • 表示「過度分泌」這件事已被確認

🎤 蔡醫師：兩者學理上本來就有重疊，臨床寫病歷是診斷導向——寫這個字想表達什麼。寫 tearing（流眼淚）也可以，只是有證據時想寫精準一點，眼科會有這個考量。

💡 嚴格定義：epiphora 是眼淚溢出眼瞼的臨床徵象（不論原因）；有些教科書把「排出不良」稱 epiphora、「分泌過多」稱 hyperlacrimation。蔡醫師的用法與此相容。

1. 正常淚膜與淚液功能單位

▾

🎤 錄音 淚膜組成

成分來源功能
水樣液主淚腺＋第三眼瞼腺水、電解質、分泌蛋白
脂質瞼板腺（meibomian gland）限制蒸發、維持淚膜穩定
黏蛋白結膜杯狀細胞＋眼表上皮讓眼淚在眼表形成良好覆蓋

🎤 傳統分三層，但實際上各成分互相作用，是動態系統。水液量足夠，不代表淚膜功能正常。

💡 犬的第三眼瞼腺約貢獻 30–50% 的水樣液，所以櫻桃眼手術要「復位」而不是切除，否則日後容易乾眼。

🎤 錄音 淚液功能單位：感覺傳入 → 腦幹 → 分泌傳出

  • 🎤 教科書把眼表、淚腺和相關神經合稱淚液功能單位（lacrimal functional unit），是功能上的統稱，不是獨立器官。
  • 🎤 角膜或結膜受刺激 → 感覺神經傳到腦幹 → 分泌神經輸出 → 淚腺調整分泌量。例如異物碰到角膜會增加眼淚。
  • 🎤 基礎分泌維持日常；刺激強時增加反射性分泌。兩者不是完全獨立，共同維持眼表環境。
  • 🎤 傳入：角膜機械或化學刺激 → 經三叉神經眼支（CN V1）傳入 → 腦幹整合 → 增加淚腺的副交感輸出。這是角膜摩擦、異物會突然流淚的基礎。
  • 🎤 感覺輸入不限眼表：狗的研究中刺激鼻子可以增加 STT 讀數；鼻黏膜麻醉後有些狗反射性分泌下降 → 支持鼻淚反射存在。但不能推論所有鼻炎都會造成臨床 epiphora。

🎤 傳出路徑：腦幹的副交感纖維 → 沿中間神經／顏面神經 → 岩大神經 → 翼腭神經節換神經元 → 節後纖維伴隨三叉神經分支 → 淚腺。

💡 逐字稿把「岩大神經（greater petrosal nerve）」聽成「大眼神經」、「翼腭神經節（pterygopalatine ganglion）」聽成「E 二神經節」，已更正。節後纖維一般描述是搭三叉神經上頜支的顴神經分支到淚腺。

🎤 所以顏面神經有兩種功能：讓眼瞼閉合、調控淚液分泌。兩種纖維走向不同，病灶影響的功能也可能不同——有些只是閉眼不全，有些連淚液分泌都下降。看到顏面神經異常時，要分別檢查眨眼功能和淚液量。

🎤 錄音 淚腺細胞怎麼分泌

  • 🎤 神經末梢釋放：乙醯膽鹼 → 細胞內鈣離子訊號；VIP（血管活性腸肽）→ cAMP 訊號。
  • 🎤 細胞受刺激 → 改變離子運輸、建立滲透梯度 → 水跟著進入腺腔；同時釋放分泌蛋白，導管再調整成分。所以神經調控影響的不只是量，也影響組成。
  • 🎤 交感神經也參與，作用依受體與細胞種類而不同，不能簡化成增加或抑制。這些機制多來自齧齒類等比較生理研究。

💡 臨床連結：pilocarpine（膽鹼促效劑）口服或局部可用於神經性乾眼，就是在補這條副交感路徑；而 atropine 會降低 STT。

2. 眨眼、眼瞼貼合與鼻淚管路徑

▾

🎤 錄音 完整眨眼才能鋪開淚膜

  • 🎤 完整眨眼可以重新鋪展淚膜；眼瞼和眼球良好貼合，眼淚才會往內眼角匯集。
  • 🎤 28 隻西施犬研究的箱形圖：完整眨眼中位數約每分鐘 2.5 次，不完整眨眼約每分鐘 15 次。這群狗水液量足夠，但眼表和淚膜穩定性仍有異常。
  • 🎤 檢查時要看每一次眨眼是否完整，不能只看有沒有眨。這張圖不能單獨證明個別病患流淚的原因，但提醒我們保定前先觀察自然眨眼。

💡 短吻犬眼球突出、眼裂大，常見「眨了但沒閉到底」（lagophthalmos），下方角膜中央容易乾、色素沉著。

🎤 錄音 鼻淚管解剖與 CT 淚道造影

上、下淚點（1a、1b）
→
上、下淚小管
→
淚囊（2）

鼻腔
  • 🎤 CT 淚道造影：從淚點注入顯影劑，CT 追蹤後重建 3D（綠色＝顯影管道，灰色＝骨骼）。可以辨認路徑和病變位置，和單純測淚液量是不同的資訊。
  • 🎤 比較英國鬥牛犬 vs 羅德西亞背脊犬：短吻犬的路徑比較擁擠、前段方向改變；長吻犬鼻淚管沿著長吻部向前延伸。
  • 🎤 路徑形狀不同 ≠ 已經阻塞，還要配合其他檢查判斷功能。

3. 分泌增加：眼表刺激、淚液品質與神經

▾

🎤 錄音 反射性流淚的四個來源

來源例子
角膜上皮缺損、潰瘍、角膜炎
結膜結膜炎、結膜囊異物、藏在第三眼瞼後方的異物
外界刺激風、粉塵、煙霧、化學物質 → 急性或間歇性流淚
眼內疼痛葡萄膜炎、青光眼

🎤 單側流淚＋瞇眼、畏光或抓眼睛 → 優先考慮疼痛與刺激來源。檢查要搭配螢光染色＋適當的眼壓評估。

🎤 錄音 毛髮與睫毛接觸

類型特徵
倒睫（trichiasis）正常位置長出的毛髮朝向眼表；鼻褶毛、眼周毛摩擦也屬這類
雙排睫（distichiasis）從瞼板腺開口附近長出
異位睫（ectopic cilia）穿出瞼結膜直接刺角膜 → 明顯疼痛＋局部潰瘍
  • 🎤 下眼瞼倒睫照片：細小毛髮從眼瞼邊緣伸向眼表，沒有放大觀察很容易漏掉。
  • 🎤 要放大看，必要時翻開眼瞼、檢查第三眼瞼後方。
  • 🎤 找到異常毛髮後要確認是否真的接觸到病灶：有些柔軟的雙排睫不是傷害主因，不能看到就斷定它造成流淚。

💡 異位睫典型是年輕犬、上眼瞼中央、角膜 12 點鐘附近的垂直線狀潰瘍，非常痛、治療反應差。

🎤 錄音 淚液品質：淚液結晶（ferning）試驗

  • 🎤 取淚液在玻片上乾燥，顯微鏡看結晶分支型態。0–1 級：分支密集、間隙小；2–3 級：分支較粗、間隔變大；4 級：規則分支明顯變少或沒有清楚結晶。
  • 🎤 原理：電解質、蛋白質的成分比例會影響乾燥時的結晶 → 可以提示組成是否異常。
  • 🎤 限制：不能指出是黏蛋白、脂質還是哪種電解質不足；圖片來自前面的西施犬研究，不同族群結晶狀態不同，不能當主要依據。臨床要結合淚液量（STT）＋淚膜破裂時間（TBUT）＋眼表檢查。

🎤 錄音 顏面神經異常

運動功能受損

  • 眼輪匝肌無法正常閉眼
  • 淚膜分布不均、鋪展與收集效率下降
  • 若感覺與分泌反射保留 → 眼表刺激反而增加反射性分泌

分泌功能受損

  • 同時傷到往淚腺的副交感路徑
  • 水液分泌下降 → 神經性乾眼
  • 眼周看起來濕，不代表分泌正常
  • 🎤 2026 年一篇犬顏面神經功能異常的回溯研究，強調了神經性乾眼與角膜傷害的重要性。
  • 🎤 檢查：自然眨眼、眼瞼反射、角膜感覺、STT，再配合其他神經與耳部徵象定位。

💡 神經性乾眼常見同側鼻孔乾（外側鼻腺也受同一副交感路徑支配），是很好用的定位線索。中耳炎、特發性顏面神經麻痺、甲狀腺功能低下都要想到。

🎤 錄音 鱷魚淚症候群（味覺性流淚）

  • 🎤 人醫：顏面神經受傷後，原本支配唾液分泌的纖維錯誤再生到淚腺，進食咀嚼時單側流淚。說明分泌迴路可能接錯線。
  • 🎤 犬貓直接證據有限，不能列為常見鑑別診斷。飼主說吃東西時流淚，仍要先排除常見的眼表與引流問題。
  • 🎤 有腮腺管轉位術病史時，要想到是唾液流到眼表，和味覺性流淚是不同狀況。

🎤 蔡醫師補充：鱷魚吃獵物時流眼淚的傳說，比喻假惺惺的眼淚。咀嚼、打哈欠時流淚在動物不算罕見，可能是內眼角下方積了淚、咀嚼時溢出來；真正神經錯接的他看過很少，動物反而比較常走向神經性乾眼。

4. 收集與排出異常

▾

🎤 錄音 入口位置：眼瞼與淚點

  • 🎤 獵犬下眼瞼外翻照片：結膜外露、眼瞼無法貼合眼球 → 收集與眼表保護受影響，但不代表淚道阻塞。
  • 🎤 眼瞼外翻／鬆弛、眼球眼瞼貼合不佳 → 眼淚無法有效集中；內側下眼瞼內翻 → 改變淚點方向，接不到眼淚；內眼角構型改變 → 容納、匯聚眼淚的能力下降。
  • 🎤 共同點：管道可能沒塞，問題在入口和周邊的構型。所以這類狗沖洗試驗通過，仍會持續流淚。

🎤 錄音 淚點與淚小管本身的病變

類別重點
先天性幼年或一直流淚 → 淚點未開通（imperforate punctum）、閉鎖、發育異常；但要先排除眼表刺激與構型問題
外傷內眼角附近損傷可能同時影響淚點與淚小管
醫源性手術後狹窄
結膜變形慢性發炎後狹窄；貓曾有嚴重結膜病或沾黏（如 FHV-1 後 symblepharon）→ 淚點被拉扯、扭曲

🎤 檢查除了找到淚點，也要看位置、開口和周圍組織。能不能重建開口或改道，取決於後方還有沒有可用的通道把淚液排到鼻腔。

💡 淚點未開通多見於可卡、貴賓等，通常是下淚點；沖洗上淚點時，下淚點處的結膜會鼓起來，剪開即可。

🎤 錄音 淚囊炎與管腔內阻塞

  • 🎤 原因：異物（如草籽）、發炎碎屑、黏膜腫脹，位置多在淚囊與鼻淚管近端。
  • 🎤 圖：箭頭指向內眼角下方的瘻管開口，是慢性淚囊炎的表現。這個位置反覆腫脹、流液時，除了皮膚與眼科問題，也要檢查淚液排出路徑。
  • 🎤 線索：持續性單側流淚、黏稠膿性分泌物、反覆結膜炎、內眼角下方腫痛或瘻管。這些常讓人一直換抗生素，但異物與引流障礙還在就會復發。
  • 🎤 沖洗時記錄阻力、逆流方向、是否帶出分泌物或異物，必要時取樣（培養、細胞學）。
  • 🎤 治療：控制發炎與感染，同時處理阻塞原因，評估能否恢復通暢。慢性病程會留下狹窄或纖維化。

🎤 錄音 管腔外壓迫

  • 🎤 附近腫塊、鼻腔病變、顏面外傷、骨骼變形都可能影響引流。
  • 🎤 牙根周圍疾病是否影響淚管要看病灶位置和影像，不能把所有流淚都歸咎牙齒。
  • 🎤 慢性單側阻塞性溢淚合併鼻腔分泌物增加或疼痛 → 檢查範圍擴大到鼻腔、口腔與周圍組織。一般檢查和沖洗找不出原因 → 考慮 CT 或淚道造影，找狹窄位置，也確認有沒有壓迫、破壞或需要取樣的病灶。

💡 逐字稿寫「慢性單側阻塞性耳聾」「C D P T」，依上下文應是「溢淚」和「CT」。

🎤 錄音 短吻犬貓：多個機制同時存在

  • 🎤 短吻動物可能同時有鼻淚管副開口、內側下眼瞼內翻、毛髮刺激、引流路徑改變，要逐項檢查。
  • 🎤 3D CT 重建：上下淚小管 → 淚囊 → 鼻淚管；白色箭頭指出副開口附近顯影劑進入鼻腔——液體不一定走完整條管道才到鼻孔。CT 橫切面也標出左右兩側副開口區域。
  • 🎤 所以螢光染劑如果先從副開口排到較後方的鼻腔，前方鼻孔看不到染劑，Jones test 陰性也不能判定阻塞。研究把這個試驗和沖洗、CT 造影一起比較。
  • 🎤 這是解剖差異，不能單憑副開口或短吻外觀就診斷 epiphora 的原因。短吻貓也有路徑變化的研究，但右邊是狗的影像，不能直接當貓的解剖圖。

💡 實務小技巧：Jones test 陰性時，也可以看口咽部（張嘴用鈷藍光照）有沒有螢光，短吻犬貓常流到後鼻腔再到咽部。

5. 檢查順序與三種引流檢查

▾

🎤 錄音 溢淚病患的檢查順序

  1. 🎤 病史：多久了、單側或雙側、有無疼痛或其他症狀、之前做過什麼處置。
  2. 🎤 保定前自然觀察：自然眨眼、閉合程度、眼淚從哪裡溢出。
  3. 🎤 STT：排在點藥和明顯的眼表操作之前，減少干擾。STT-1 包含基礎＋反射分泌，數字高不能直接判定原發性分泌過多。
  4. 🎤 放大檢查：眼瞼、睫毛、淚點、結膜、第三眼瞼。
  5. 🎤 螢光染色＋適當的眼壓評估。
  6. 🎤 眼表表現和水液量不一致 → 評估淚膜穩定性（TBUT）。
  7. 🎤 懷疑收集或排出障礙 → 引流檢查。

🎤 單側或雙側可以調整鑑別診斷順序，但不能單獨作為診斷。

🎤 錄音 三種引流檢查

檢查做法陽性代表限制
螢光染劑通過試驗（Jones test）眼表滴螢光染劑，觀察同側鼻孔至少有一條可通行的路徑陰性要考慮通過時間、頭型、測試方法、副開口 → 不能證明完全阻塞
鼻淚管沖洗經淚點放入沖洗管，慢慢注入生理食鹽水；看是否通過、阻力、逆流、帶出黏液或膿施加壓力下是通的沖得通不代表平常排得夠好
CT 淚道造影經淚點注入顯影劑，CT 顯示淚道與周圍構造找出異常的位置需要麻醉、設備

🎤 範例圖：上排短吻犬（逐字稿聽成「發抖」❔）、下排一般頭型米克斯；A 淚小管、B 淚囊、C 鼻淚管骨內段、D 中段、E 遠端。這是比較解剖位置，不是上排異常、下排正常。三種檢查互補，還要配合眼表、眼瞼、淚點檢查一起判讀。

💡 Jones test 一般約 5 分鐘內出現於鼻孔，貓與短吻犬可能更久或根本不出現在前鼻孔。

🎤 錄音 蔡醫師：門診做得到沖洗嗎？

  • 🎤 最容易成功的是大型、溫和的拉布拉多、黃金：熟悉淚點位置、找過兩三次之後，點局部麻醉藥就可以在門診做。
  • 🎤 已經確認可能塞住、又要硬在門診通，加上狗貓反抗 → 很難。建議鎮靜或輕度麻醉。
  • 🎤 器材：大狗用鼻淚管 cannula（他們用人用的，前端有頭，插進去推就能沖，不用另外壓住淚點）；小狗或貓鎮靜後用留置針的軟外套管。
  • 🎤 淚點很難找時，先用鈍頭的淚點擴張器（逐字稿「筆袋杆 platter」❔，應是 punctal dilator）插進去轉一轉把開口撐大，再換軟針或 cannula 去沖。以前做 X 光／CT 造影就是這樣打顯影劑。

6. 依病灶選擇治療

▾

🎤 錄音 主報的治療原則

病灶處理
眼表、眼內疾病造成的反射性流淚控制原發病，再評估是否還有 epiphora
眼瞼或毛髮接觸依實際傷害與功能影響，考慮矯正手術
淚膜不穩定加強眼表保護，評估相關腺體功能
異物、淚囊炎、狹窄移除病因、恢復通暢，控制伴隨的發炎與感染；有些需要放引流管維持；複雜或不可逆病變轉專科手術評估
  • 🎤 治療後追蹤：是否還濕、舒適度、角膜健康、眼瞼功能、分泌物。
  • 🎤 多個機制同時存在時，單一處理可能只改善一部分，短吻構型病例尤其如此——要事先和飼主溝通可能殘留的流淚。

🎤 錄音 臨床情境整理

情境先查什麼
突然單側流淚＋明顯瞇眼角膜傷害、異物、眼內疼痛
長期流淚、眼表相對平靜眼瞼貼合、淚點位置、引流功能
合併閉眼不全或顏面不對稱運動、感覺、分泌功能分開檢查
多種異常同時存在處理後再追蹤剩下的症狀
眼淚流出來是我們看到的結果；沿著分泌、分布、收集、排出的路徑檢查，才知道問題在哪裡。

🎤 錄音 討論：流淚很多還要點人工淚液嗎？

  • 🎤 提問：淚液不穩定的治療是增加潤滑，但淚液已經過多，再點玻尿酸，飼主會覺得更濕？
  • 🎤 主報：一開始是刺激（多半是機械性）造成分泌增加，但這些反射淚只是眾多成分中比較不重要的一部分，淚膜本身已經不健康，還是需要人工淚液讓眼表長期維持濕潤。
  • 🎤 主持人：可以跟飼主說，淚液過多其實是保護機制，我們是在減緩刺激、處理根本原因。
  • 🎤 蔡醫師：就像今天那隻眼瞼內翻的貓，都要給玻尿酸——毛或眼瞼刺激就是一種異物刺激，在眼表加一層潤滑層（不是保濕），讓摩擦刺激減少。效果一定有限，真正內翻還是要處理。

🎤 錄音 討論：鼻淚管阻塞給類固醇？要不要通？

  • 🎤 主持人：阻塞時不去通，好像只能給類固醇（口服或點眼）？蔡醫師：其實也只能這樣。
  • 🎤 難處理的是先天開口異常、長期發炎、淚囊發炎、纖維化。年輕或常常發炎塞住的，初期類固醇效果非常好。
  • 🎤 但如果是紅貴賓、白貴賓，飼主說兩三個月大就有淚痕、一歲才來看 → 給類固醇基本上沒效，要回到改善淚液氧化狀態，或真的檢查鼻淚管構造。
  • 🎤 反過來，最近兩週才流淚增加、現場看到結膜炎 → 推測鼻淚管有發炎。他覺得局部類固醇（點眼）效果比口服好；想一次衝成功時會加很低劑量口服類固醇。
  • 🎤 前提：突然流淚要先排除睫毛異常、角膜潰瘍等常見問題；角膜沒事、只有結膜炎、螢光試驗不通 → 懷疑鼻淚管阻塞，這時給類固醇，在狗好的機會蠻高。
  • 🎤 什麼時候建議麻醉通？現在大家（包括他自己）多半不通：要成功得很早期、不是明顯纖維化、而是有東西堵在裡面；實際成功率大約 10 隻 1–2 隻，又要麻醉、費用不高、要跟飼主解釋很多。這是醫師這邊的考量，不是動物的考量。
  • 🎤 值得做的情況：判斷阻塞與發炎機會高，或壓內眼角下方能壓出分泌物——這時成功率高，可以建議麻醉下沖洗，甚至把類固醇打進淚囊。
  • 🎤 通完之後：沿用以前的做法，在鼻淚管上下都留一點類固醇（學理上不確定有沒有效）；真的只能做一邊就做下面，下淚小管比上面大一點。
  • 🎤 點 NSAID 可以嗎？可以，但類固醇成功率都不高了，用 NSAID 更不知道有沒有效。
  • 🎤 蔡醫師也提到，這幾年比較少做之後，年輕醫師找淚點的速度和能力變差了，鼓勵大家練。

💡 用類固醇前一定要先做螢光染色確認沒有角膜潰瘍；貓有 FHV-1 病史時局部類固醇要特別小心。

7. 蔡醫師延伸：淚痕、口服淚痕產品與淚液液態切片

▾

🎤 錄音 淚痕與市售口服產品

  • 🎤 貴賓、白色犬種常有很大一條淚痕，有些和遺傳、發炎、皮膚問題、鼻淚管開口有關，研究很多但還沒有被徹底弄清楚。
  • 🎤 市售口服淚痕產品（如 Angel Eye）主打抗氧化劑，有的加 B12、營養劑、胺基酸、神經相關成分。少部分狗吃了有效。
  • 🎤 改善淚痕不一定是眼淚變少：可能還是會流，只是不變成淚痕。淚液中的含鐵成分接觸空氣、過度氧化會變鐵鏽色。
  • 🎤 有些醫師發現狗吃 metronidazole 或 doxycycline（因皮膚病等原因）後淚痕變少——可能是改變了淚液成分與氧化，而不是流量。
  • 🎤 「水汪汪」眼藥的適應症是白內障，也有抗氧化成分，但廠商沒有說能治淚痕；可以試，合理但效果難講。

💡 淚痕的紅棕色一般認為主要來自淚液中的卟啉（porphyrin），加上潮濕處的細菌、馬拉色菌；蔡醫師提的是乳鐵蛋白（含鐵）氧化的說法。早期的 Angel Eyes 含 tylosin（抗生素），在美國曾被 FDA 要求下架，現行配方已改。長期用抗生素只為了淚痕不建議。

🎤 錄音 淚液當「液態切片」

🎤 人醫與獸醫學界有 liquid biopsy 的概念：拿體液做分析當作類似切片。動物已有不少論文把淚液做蛋白質體分析，用來評估眼睛發炎、推測乾眼症、甚至腫瘤。日本、美國很多研究在做，未來「一滴眼淚看到事情」可能有突破，值得期待。

🎤 錄音 其他提到的

  • 🎤 蔡醫師推薦近兩年關於貓虹膜色素沉著（FDIM）的論文（含 OCT、追蹤 12 年以上的長期研究，2026 年 6 月接受刊登），討論會不會惡化、轉移、要不要早點摘眼——可以讓大家跟飼主多講很多。
  • 🎤 讀書會兩週一次、晚上 10 點；下一次在 12 月 2 日左右（12/9 實作課前），主報待定。新成員劉醫師（臨床病理／細胞學背景）會參加眼科實作，想學裂隙燈、眼壓量測（TonoVet 量測變異大）、間接眼底鏡。

💡 貓虹膜黑色素病變可參考同站 FASAVA 03 貓眼的獨特之處：FHV-1 與 FDIM（Kayes 2025、Gregorio 2026 等）。
